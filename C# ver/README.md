# 逐字输入器（独立版 / C# + Win32）

不依赖浏览器的独立桌面版逐字输入器。用 **Win32 `SendInput` + `KEYEVENTF_UNICODE`** 发送**真实键盘事件**：
- 中文/符号原生支持（不需要剪贴板回退、不依赖输入法）；
- 不触发网页的 `paste` 事件（比"逐字剪贴板+Ctrl+V"方案隐蔽得多）；
- 可用于任何接收键盘输入的程序：浏览器网页、IDE、记事本、终端、聊天框等。

## 环境要求

- Windows 10 / 11（内置 .NET Framework 4.8）
- **无需安装任何 SDK**——构建使用系统自带的 `csc.exe`

## 构建

```bat
build.bat
```

或命令行（构建完不暂停）：

```bat
build.bat nopause
```

成功后在同目录生成 `CharByInputer.exe`（约 13 KB，可直接复制到别处运行）。

## 使用方法

1. 打开程序，在文本框里粘贴要输入的文本（换行会作为一次回车发送）。
2. 设置速度 `ms/字`（默认 10）与「随机抖动」（默认不勾选，固定节奏）。
3. 点「**开始输入**」→ 主窗口状态栏出现倒计时，窗口保持打开。
4. **在倒计时 3 秒内点击目标输入框**（把输入焦点放到那里）。
5. 倒计时结束开始逐字输入，主窗口状态栏显示进度。

## 快捷键

| 按键 | 作用 |
|---|---|
| `F8` | 停止 / 取消（输入中或倒计时中）；空闲时按 = 唤出窗口 |
| `F9` | 显示 / 隐藏主窗口 |

主窗口**始终置顶（TopMost）**，且显示/更新/置顶时不抢键盘焦点（`ShowWithoutActivation`），不会打断正在输入的目标；若遮挡目标位置，用 `F9` 临时隐藏。

输入过程中直接关闭窗口会被拦截（先取消输入，输入流程结束后窗口重新出现，再关闭即可）。

## 特性与实现

- **`TypeSender.cs`**：`SendInput` + `KEYEVENTF_UNICODE` 逐字发送（按下+抬起两个事件），特殊字符映射为虚拟键（回车/Tab/退格/Esc）；Windows 的 `\r\n` 已在发送前归一化为一次回车（不会出现行间空行）。
- **`MainForm.cs`**：WinForms 界面；3 秒倒计时 + `CancellationToken` 取消；全局热键用 `RegisterHotKey`（`MOD_NOREPEAT`）；主窗口 `TopMost` 置顶，`ShowWithoutActivation` 保证显示/唤出不抢焦点；倒计时与输入进度显示在主窗口状态栏。

## 已知限制

- **无法输入到"以管理员身份运行"的窗口**（UAC 用户界面隔离）；如需输入管理员窗口，请同样以管理员运行本程序。
- **UAC 安全桌面**（Ctrl+Alt+Del 界面）无法输入。
- 单个 Unicode 字符限制在 BMP 内（常用汉字/标点/符号均可；极少数拓展区字符，如部分 emoji，可能无效）。
- 目标必须在前台且可接收键盘输入（网页中请在文本框里放置好光标，由倒计时期间点击完成）。
- 逐字延迟基于 `Task.Delay`，会受系统调度影响（毫秒级误差，不影响使用）。
