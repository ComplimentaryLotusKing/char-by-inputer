# char-by inputer

一个浏览器扩展：将需要粘贴的内容以字符形式模拟手动逐个输入，可用于educoder.net代等禁止复制粘贴的网站。  
本扩展由以下 4 个文件组成：

- `manifest.json`
- `popup.html`
- `popup.js`
- `content.js`

## 安装步骤

1. **下载源码**

   从仓库中依次下载 4 个文件，或点击仓库右上角 `Code` → `Download ZIP`，下载后解压。确保所有文件在同一级目录。

2. **打开浏览器扩展管理页**

   Chrome：地址栏输入 `chrome://extensions/`  
   Edge：地址栏输入 `edge://extensions/`

3. **加载扩展**

   在扩展管理页右上角，打开「开发者模式」。  
   点击「加载未打包的扩展程序」，在弹出的窗口中，选择源码所在的文件夹，确认即可。

## 使用方法

1. 在网页可编辑区域中点击一下，放好光标。
2. 点击工具栏上的扩展图标。
3. 在弹窗中粘贴要输入的文本。
4. 按需调整输入速度，点击「开始输入」。
